# Наш бюджет — установка (≈15 минут)

## 1. Google-таблица и сервер
1. Создай новую Google-таблицу «Наш бюджет».
2. **Расширения → Apps Script.** Удали всё в редакторе и вставь содержимое `Code.gs`.
3. **Настройки проекта (шестерёнка)** → часовой пояс `Europe/Warsaw`.
4. Выбери функцию `setup` → **Выполнить** → разреши доступ.
   В **Журнале выполнения** появится `КЛЮЧ ДОСТУПУ: xxxxxxxxxx`. Сохрани его.
   В таблице появятся листы `Tx`, `Limits`, `Funds`, `Settings`.
5. **Развернуть → Новое развертывание → Веб-приложение.**
   - Выполнять от имени: **меня**
   - У кого есть доступ: **Все**
   Скопируй адрес вида `https://script.google.com/macros/s/…/exec`.

Доступ «Все» значит: без ключа сервер ничего не отдаёт и не принимает.

## 2. Приложение на GitHub Pages
1. Новый репозиторий (например, `budget`). Загрузи в корень файлы из этой папки:
   `index.html`, `manifest.json`, `sw.js`, `icon-180.png`, `icon-192.png`, `icon-512.png`.
   `Code.gs` и `README.md` загружать не нужно.
2. **Settings → Pages → Deploy from branch → main / root.**
3. Через минуту приложение откроется по адресу `https://<логин>.github.io/budget/`.

## 3. Оба iPhone
1. Открой адрес в **Safari** → «Поделиться» → **«На экран „Домой“»**.
2. Запусти с иконки → шестерёнка → вставь адрес `/exec` и ключ → выбери, кто ты.
3. У Маши то же самое, только «Маша».

## Как менять лимиты и копилки
Прямо в таблице: лист `Limits` (лимиты), `Funds` (внесок в месяц, цель, стартовый баланс),
`Settings` (`income_plan`, `cycle_day` = 10). Приложение подхватит изменения при следующем открытии.

## Если поменял Code.gs
**Развернуть → Управление развертываниями → карандаш → Версия: новая.** Адрес `/exec` останется тем же.

## Офлайн
Записи без интернета сохраняются в очереди на телефоне и отправятся сами, когда появится сеть.
